# Sweet Crumbs Bakery — React

React/Vite conversion of the 5 supplied Stitch designs.

## Pages
- `/` Home
- `/bakery` Menu
- `/about` About
- `/gallery` Gallery
- `/contact` Contact

## Run
```bash
npm install
npm run dev
```
Then open the Vite URL (normally http://localhost:5173).

## Build
```bash
npm run build
```

The original supplied Stitch HTML is kept in `src/pages/raw/` so the visual design remains faithful while React Router controls page navigation.
